Machine

Kept in this browser. A suspended machine resumes with the size it had; Boot instead starts it from its disk with this one.

Network

Log in…

On a computer of yours, run tailcat serve exit-node (tailcat) and paste the address it prints: the machine gets that computer's network. Keep the address to yourself: it lets anyone in. tailcat's public relays are rate-limited; your own relay isn't.

Screen

A text console (fbcon) keeps the size it started with: a new size takes effect at the next boot (Restart), and the console is centred until then. A desktop takes it when it starts; whether it follows a change is up to its compositor (sway doesn't).
