Network

How should this machine reach a network? Its network card is always there: connecting doesn't restart it.

Without an auth key you log in, in a new tab, and the machine stays on the tailnet over reloads. With one there's no login, the key isn't kept and the node is ephemeral. A Headscale must answer /key with CORS headers.

On that computer run tailcat serve exit-node (tailcat) and paste the address it prints: the machine reaches what that computer reaches, its LAN and the internet. Keep the address to yourself: it lets anyone in.

The machine gets a tailcat address of its own, kept in this browser. With it another computer runs tailcat ssh <address> to log in to the guest's sshd, or tailcat <address> <port> for any port the guest listens on.

Advanced

Your own derper's host or host:port: faster than tailcat's public relays, which are rate-limited. Used when the machine doesn't go online through a computer of yours (that computer's relay serves then).

Screen

A text console (fbcon) keeps the size it started with: a new size takes effect at the next boot (Restart), and the console is centred until then. A desktop takes it when it starts; whether it follows a change is up to its compositor (sway doesn't).
